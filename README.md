# Smithing Mod (modid)

Небольшой мод для Minecraft, добавляющий кузнечную цепочку: стальные кольца и пластины,
кольчужную и стёганую броню, дублёную кожу, а также **улучшенный верстак** — отдельную
версию верстака 3×3, которая принимает **только** кастомные рецепты мода и не крафтит
ванильные предметы.

Ключевой объект — **Улучшенный верстак (Custom Crafting Table)**: блок, открывающий
собственный интерфейс крафта 3×3 с изолированным набором рецептов.

---

## Требования (проверенная конфигурация)

Поддержка других версий **не гарантируется** и не тестировалась.

| Компонент | Версия |
|-----------|--------|
| Minecraft | 1.20.2 |
| Загрузчик | Forge 47.2.0 |
| Java | 21 (JDK 21) |
| Сборка | Gradle (ForgeGradle 6), `gradlew build` |

Зависимостей сверх Forge нет.

> Если ваша среда отличается от таблицы выше — мод может не запуститься.
> Используйте именно Minecraft 1.20.1 + Forge 47.2.0 + JDK 17.

## Установка

1. **Подготовьте совместимую среду.**
   Установите Minecraft 1.20.1 и Forge 47.2.0 (через официальный установщик Forge).
   Убедитесь, что используется JDK 17.
2. **Соберите JAR.**
   В корне проекта выполните: gradlew build
3. Готовый файл появится в `build/libs/` (файл без суффикса `-sources`/`-dev`).
3. **Поместите JAR в папку `mods`.**
   Скопируйте итоговый `.jar` в каталог `mods` вашего профиля Forge 1.20.1
   (обычно `%APPDATA%\.minecraft\mods` на Windows или `~/.minecraft/mods` на Linux/macOS).
4. **Запустите игру.**
   Запустите профиль Forge 1.20.1. В главном меню проверьте `Mods` — мод `modid`
   должен быть в списке без ошибок.
5. **Убедитесь, что объект доступен.**
   В творческом режиме откройте вкладку **«Кузнечные предметы» (Smithing Items)** —
   там должен быть **Улучшенный верстак**. В выживании его можно скрафтить
   (см. ниже).

## Получение и использование

### Улучшенный верстак (Custom Crafting Table)

**Как получить (крафт 3×3 на обычном верстаке):**

I I I
S A S
S C S

- `I` — железный блок (`minecraft:iron_block`)
- `S` — каменный кирпич (`minecraft:stone_bricks`)
- `A` — наковальня (`minecraft:anvil`)
- `C` — обычный верстак (`minecraft:crafting_table`)

Результат: 1 × Улучшенный верстак.

**Основные свойства:**

- Это блок с собственным интерфейсом крафта 3×3.
- Принимает **только кастомные рецепты мода**. Ванильные рецепты в нём
  **не работают** — слот результата остаётся пустым.
- Поддерживает shift-click (быстрый перенос результата в инвентарь).
- При закрытии интерфейса предметы из сетки крафта возвращаются игроку.

**Пример использования в игре:**

1. Поставьте Улучшенный верстак и откройте его (ПКМ).
2. Выложите в сетку 4 железных слитка квадратом 2×2 (паттерн `II / II`).
3. В слоте результата появятся **4 стальные пластины** — заберите их.
4. Выложите 4 железных самородка «кольцом» (` N / N N / N `) — получите
   **4 стальных кольца**, из которых затем крафтится кольчужная броня.

> В обычном верстаке эти рецепты не появятся — они зарегистрированы только
> для Улучшенного верстака.

### Прочие предметы мода (кратко)

- **Стальная пластина / Стальное кольцо** — промежуточные компоненты.
- **Кольчужная броня** (шлем, нагрудник, поножи, ботинки) — крафтится из стальных колец
  в Улучшенном верстаке.
- **Дублёная кожа** — крафтится из кожи, щелочного порошка и ведра воды (3 шт. за крафт).
- **Стёганая броня** — крафтится из стальных колец и дублёной кожи.
- **Щелочной порошок** — получается из **Блока щелочи** (1 блок → 4 порошка, shapeless).
- **Молот кузнеца** — инструмент, крафтится из железных слитков и палок.

## Известные ограничения

- Улучшенный верстак **намеренно не поддерживает ванильные рецепты** — это не баг,
  а задуманное поведение.
- Поддерживается только связка **Minecraft 1.20.1 + Forge 47.2.0 + JDK 17**;
  другие версии не тестировались.
- Рецепты мода зарегистрированы статически в `CustomCraftingTableMenu`
  (при загрузке класса), а не через датапак — изменение рецептов требует пересборки.
- Плавка `rotten_flesh → leather` (smelting, exp 0.3, 200 тиков) описана в JSON,
  но применяется стандартной печью, а не Улучшенным верстаком.
